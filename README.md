"# XSS-Sentinel" 
Beyond Detection: An Intelligent Ensemble & Deep Learning Approach for XSS Type Classification and Defense

Note on Dataset Re-categorization:
The original Kaggle XSS dataset does not provide fine-grained
labels for stored, reflected, and DOM-based XSS. Following
the methodology described in the CAXF-LCCDE paper,
we re-labeled XSS samples using rule-based heuristics
derived from payload structure and JavaScript execution
patterns.
